# Роли и структура проекта

Сейчас в репозитории только каркас: страница отправляет параметры, сервер считает демо-синусоиду и возвращает кадры η(x, t), страница их анимирует.
Какие математические модели считать, решаем после того, как Анушервон закончит теоретическую часть. Тогда же раздаём задания по моделям.

## Кто за что отвечает

| Кто | Роль | Файлы |
|---|---|---|
| Анушервон | теория | `docs/` — описание моделей, уравнения, допущения |
| Ваня | бэкенд, расчёт | `backend/` — модели в `backend/models/`, сервер `main.py`, реестр `registry.py` |
| Алёна | фронтенд | `frontend/` |
| Влад | анализ | `analysis/` — данные залива, оценки, сравнение моделей |
| Саша | контракт и связка частей | `backend/contract.py`, `README.md` |

`backend/contract.py` — общий для всех файл: что модель получает (`Params`) и что отдаёт (`Result`). Менять его только через тимлида.

## Что делать до готовности теории

- **Анушервон** — теоретическая часть: какие модели подходят для задачи, их уравнения и область применимости. Результат кладём в `docs/`.
- **Ваня** — запустить проект по README, разобраться в `contract.py` и `demo.py`, посмотреть численные методы для волновых уравнений.
- **Алёна** — делать нормальный интерфейс на демо-модели: форма параметров, анимация, место под рисунок дна и под сравнение нескольких моделей на одном графике. Формат данных — `Result` в `contract.py`.
- **Влад** — собрать реальные параметры Финского залива с источниками: глубины у берега, уклон дна, высоты и периоды волн.

## Как работаем с репозиторием

- Каждый работает в своей ветке и вливает её в `main` через pull request.
- Не правим чужие файлы без договорённости.
