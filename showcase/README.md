# Финский залив 3D — эмулятор для показа

3D-карта всего Финского залива: спутниковый снимок на рельефе, вода из нашего расчёта `shallow_2d` и разрез волн в любой точке по клику. Разрез считается на лету моделями проекта `linear`, `saint_venant` и `boussinesq`.

## Развернуть как у меня

### Вариант 1. Готовое приложение (проще всего)

1. Скачайте `Финский-залив-3D.exe` со страницы релиза **showcase-3d** в репозитории (GitHub → Releases). В git файл не лежит: он весит ~300 МБ, а GitHub не принимает файлы больше 100 МБ.
2. Запустите. Windows 10/11 со встроенным WebView2 (движок Edge) — больше ничего ставить не надо: Python, модели, данные, город, дно и кэш карты уже внутри.
3. Первый запуск — 10–20 с: `.exe` распаковывается во временную папку. Если появится SmartScreen — «Подробнее» → «Выполнить в любом случае» (файл не подписан).

Новые тайлы карты, если есть интернет, кэшируются в `%LOCALAPPDATA%\FinGulf3D`.

### Вариант 2. Из исходников (Python 3.11+)

```
git clone https://github.com/Raubmorder320/mathphis-waves.git
cd mathphis-waves
git checkout vanya/showcase-3d
pip install -r requirements.txt httpx pillow scipy pywebview pyinstaller
```

Кэш карты и снимки города в git не лежат (это тайлы поставщиков, `showcase/.tiles`) — скачайте их один раз, пока есть интернет:

```
python -m showcase.tiles                 # тайлы карты всего залива, ~1000 шт.
python -m showcase.city_sat vo kronstadt # снимки z15 под детальный город
```

Запуск — окном приложения или в браузере:

```
python -m showcase.desktop                      # окно WebView2, как .exe
uvicorn showcase.server:app --port 8800         # или браузер: http://127.0.0.1:8800
```

Собрать свой `.exe` (≈ 4 мин, результат — `dist/Финский залив 3D.exe`):

```
python -m showcase.build_exe
```

### Если тормозит или зависло

- Кнопка **⏹ Стоп** в нижней панели останавливает отрисовку и расчёт — видеокарта свободна. **⟲ Сброс** или `F5` возвращают всё в исходное состояние.
- `?safe=1` в адресе (`http://127.0.0.1:8800/?safe=1`) — безопасный режим: без затопления и комнат за окнами, разрешение 1.
- Если появилось красное предупреждение «рисует БЕЗ видеокарты» — включите в браузере аппаратное ускорение и перезапустите его.

Сценарии и маска моря уже лежат в `showcase/data/`. Пересчитать их можно так:

```
python -m showcase.sea      # маска моря и глубины залива из тайлов рельефа (нужен кэш тайлов)
python -m showcase.build    # 2D-сценарии + подбор под наводнение 1975 года, ~5 мин
```

**Перед показом прогрейте кэш тайлов**, пока есть интернет: `python -m showcase.tiles`. Это около тысячи тайлов, при медленной сети минут десять. Потом карта работает без сети. Если тайла нет, вместо снимка будет тёмный фон, но вода и разрезы всё равно работают.

## Управление

| | |
|---|---|
| `1`–`4` | фокусы: весь залив · вход волны (27° в. д.) · Кронштадт и Котлин · Невская губа |
| мышь | вращать, наклонять, приближать |
| `W` `A` `S` `D` | полёт; `Q` `E` — поворот, `R` `F` — наклон, `Z` `X` — высота, `Shift` — быстрее |
| щелчок по воде | разрез волн: путь волны от западной границы до точки и три модели на нём |
| `Пробел` | пауза · `H` — скрыть интерфейс (для кадра на слайд) · `Esc` — закрыть разрез |
| `5`, `6` | детальный город: Васильевский остров, Кронштадт (включается и сам при приближении) |
| `G` | свободная камера и погружение: щелчок — мышь, `WASD` полёт, `R`/`F` вверх-вниз, `Q`/`E` крен, `Shift` ×8, колесо — скорость |

## Что на экране и что настоящее

- **Длинная волна и нагон** — расчёт `shallow_2d` на карте Влада 150 × 50, сценарии в `build.py`. Вертикаль η преувеличена (ползунок «Вертикаль η ×»), рельеф суши и дна — ×15.
- **Наводнение 1975 года** (+2,81 м у Горного института) подобрано двумя способами:
  - при волне 0,5 м нужен западный ветер **21,8 м/с**;
  - при историческом ветре 27,5 м/с нужна волна на входе **0,13 м**.
- **Разрез по клику** (`section.py`):
  - путь волны — это путь наименьшего времени пробега по воде (принцип Ферма) от западной границы до точки и дальше до берега;
  - h(s) берётся из карты глубин, на этом пути считаются ядра трёх моделей;
  - на разрезе Влада числа совпадают с таблицей 3.3 из `docs/report.md`.
- **Мелкая рябь на воде** — декоративная. Это ветровое волнение по направлению ветра сценария, каждая октава бежит со скоростью глубокой воды √(g·k). Расчётом это не является: модели мелкой воды такие волны не описывают.
- **Берег воды** — подробная маска из рельефа Terrarium (GEBCO), около 330 м на пиксель. Она только для картинки, модели считают на своей сетке.

## Детальный город (Васильевский остров, Кронштадт)

```
python -m showcase.osm_builder vo kronstadt   # здания, улицы, набережные из OSM (Overpass, по квадратам)
python -m showcase.flood_map vo kronstadt     # карта высот и препятствий для затопления
```

- **Здания OSM** (4398 и 1242) с фасадным шейдером: этажи, окна с рамами, комнаты за стеклом (interior mapping), отражение неба, вечерний свет. Улицы с тротуарами на 18 см выше и гранитным бордюром, набережные с парапетом.
- **Затопление улиц** считается на видеокарте моделью виртуальных труб (Mei et al., 2007) — это упрощённая мелкая вода. Дома — непроницаемые стены. Уровень моря на краю зоны берётся из 2D-сценария или задаётся вручную. Сетка — не больше 512 по стороне (10–11 м), не чаще 30 обновлений в секунду.
- **Производительность:** геометрия строится в WebWorker, кварталы 500 × 500 м отсекаются вне экрана. Ближе 600 м видны окна и улицы, до 3 км — блоки, дальше кварталы скрыты.
- **Ограничение:** земли без домов (DTM) для Петербурга в открытом доступе нет. Высота земли оценена из SRTM DSM фильтром минимума, точность ±2–3 м, поэтому вывод «затопит ли при +2,81 м» по этим данным неточен.

## Дно и свободная камера

```
python -m showcase.seabed    # EMODnet Bathymetry: весь залив и Невская губа (25 м, бикубически), берег по расстоянию
```

- **Дно** — EMODnet Bathymetry DTM (~58 × 115 м, в четыре раза подробнее GEBCO). Для Невской губы оно интерполировано бикубически до 25 м, береговая линия задана знаковым полем расстояний, без ступенек. Видны дамба, Котлин, протоки дельты. **Морского канала в этих данных нет**, и мы его не дорисовываем. В шейдере дна — песчаная рябь, камни на склонах, ил на глубине, каустики, поглощение света водой.
- **Вода в свободной камере** — кольцевая сетка вокруг камеры (112 тыс. вершин, шаг ~5–25 см у камеры).
  - 8 волн Герстнера по ветру сценария, частоты по ω² = g·k·tanh(k·h) для глубины под камерой.
  - На мелком волна растёт (шоалинг) и обрушается при H/h > 0,78, там пена. Пена есть и у берега, и у стен домов.
- **Под водой** — окно Снеллиуса (48,6°), подводный туман, каустики. Камера 6DOF без ограничений по углу и высоте.
